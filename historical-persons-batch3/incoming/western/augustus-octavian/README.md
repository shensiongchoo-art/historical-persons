- "First Roman Emperor" marked as reception/modern historiographical category
- Constitutional settlements (27 BCE, 23 BCE) documented as factual; interpretations flagged
- Res Gestae presented as self-presentation, not neutral history
- Ancient sources (Suetonius, Cassius Dio, Appian, Tacitus, Plutarch) cited where possible
- Testamentary adoption legal ambiguity noted (probable, not confirmed)
- Augustus military record: poor field commander per modern consensus
- Visual media: statues identified as contemporary idealized portraits, not objective likeness
