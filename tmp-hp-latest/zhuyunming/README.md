## Entity Disambiguation Notes
1. **祝允明 vs 祝枝山**: 枝山为其号，不可写作"祝枝明"或"祝允山"。以"祝枝山"闻名于通俗文化。
2. **祝允明 vs 唐寅/文徵明**: 三人为同代人且同乡（苏州），但不可将"同被并称"等同于结拜或固定组织。
3. **祝允明 vs 祝姓其他人物**: 明代祝姓人物有祝世禄（万历进士）等，不可混淆。
4. **枝山 ≠ 其他以"枝"为号者**: 枝指生特指其多指畸形，是其特征性自号。
5. **1461年出生 vs Wikipedia 生年**: 部分中文来源可能记为1460年，因农历年换算差异。此处采用墓志铭推算的1461年。
6. **江南四大才子**: 民间版本中"祝枝山"为一员，但正史为"吴中四才子"。两套称呼不可混用。
